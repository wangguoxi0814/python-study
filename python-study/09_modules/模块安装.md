# 模块安装

## pip install 模块名

## 可选依赖安装: 
- pip install 模块名[可选依赖]
  - pip install passlib[bcrypt]
    - 安装passlib时，同时安装符合passlib要求的bcrypt
    - passlib大部分功能不需要bcrypt的支持，只有需要bcrypt加密时才需要安装bcrypt，所以设置为可选依赖

### pip install passlib bcrypt 和 pip install passlib[bcrypt]的区别？
- 前者是安装独立的两个模块，各自版本都是最新的，当然也可以自己指定
- 后者可选依赖安装，所安装的bcrypt一定是符合passlib要求的
